# Development Environment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One reproducible conda environment, `climt-dev`, that runs current climt, numba, JAX on CPU, the JAX dynamical core and the optional I/O stack in the same process, plus `climt.show_versions()` for bug reports.

**Architecture:** conda supplies Python 3.11 only; pip installs everything else from `envs/climt-dev.in`; `pip freeze --exclude-editable` is the lock. A bootstrap shell script builds the environment from the lock, and a Python verification script reports each capability by name. `show_versions()` reads installed metadata without importing the packages.

**Tech Stack:** conda, pip, bash, Python 3.11, `importlib.metadata`, pytest.

**Spec:** `docs/superpowers/specs/2026-11-14-dev-environment-design.md`

## Review Focus

- **A reported package is not installed** (e.g. no zarr): `show_versions()` returns `None` for it and prints `not installed`, and does not raise. Pinned by Task 1.
- **A reported package is installed but broken on import** (e.g. scipy with unloadable Fortran extensions, JAX with `jax-metal`): `show_versions()` still returns, because it never imports it. Pinned by Task 1's subprocess test for packages `import climt` does not already load (scipy is loaded by climt via pint, so for scipy this holds by construction, not by test). A compiled climt extension that raises a non-ImportError (numpy ABI mismatch, climt#174) is reported, not raised: pinned by `test_show_versions_survives_a_broken_compiled_extension`.
- **`climt-dev` already exists** when the bootstrap runs: the script stops with a message naming `--recreate` and exit status 2; it does not reinstall over or delete it. Pinned by Task 2.
- **No Fortran toolchain** (`gfortran` missing or the build fails): the bootstrap falls back to `CLIMT_PURE_PYTHON=1 pip install -e`, and the verification script prints the Fortran row as `MISSING (optional)` and still exits 0 without `--strict`. Verify half pinned by Task 2; the bootstrap fallback by `test_bootstrap_falls_back_to_pure_python_when_the_compiled_build_fails` (added at final review).
- **`GFS_DYCORE_DIR` unset or not a directory:** the dycore step is skipped with a one-line notice; verification prints the dycore row as `MISSING (optional)`. Pinned by Task 2.

```python
import io
import subprocess
import sys

import climt
from climt._core.versions import REPORTED_PACKAGES


def test_show_versions_returns_core_keys_and_every_reported_package():
    out = io.StringIO()
    info = climt.show_versions(file=out)
    assert info["climt"] == climt.__version__
    assert info["python"].count(".") == 2
    assert isinstance(info["fortran_extensions"], bool)
    assert isinstance(info["platform"], str) and info["platform"]
    for name in REPORTED_PACKAGES:
        assert name in info
    assert info["numpy"] is not None
    assert info["sympl"] is not None


def test_show_versions_prints_one_line_per_key_in_order():
    out = io.StringIO()
    info = climt.show_versions(file=out)
    lines = out.getvalue().splitlines()
    assert [line.split(":")[0] for line in lines] == list(info.keys())
    assert lines[0] == "climt: {}".format(climt.__version__)


def test_missing_package_is_none_and_printed_as_not_installed(monkeypatch):
    import climt._core.versions as versions
    monkeypatch.setattr(
        versions, "REPORTED_PACKAGES", ("numpy", "surely_not_a_real_package_xyz"))
    out = io.StringIO()
    info = versions.show_versions(file=out)
    assert info["surely_not_a_real_package_xyz"] is None
    assert "surely_not_a_real_package_xyz: not installed" in out.getvalue()


def test_show_versions_does_not_import_reported_packages():
    code = (
        "import sys, io, climt\n"
        "before = set(sys.modules)\n"
        "climt.show_versions(file=io.StringIO())\n"
        "new = set(sys.modules) - before\n"
        "bad = [m for m in ('jax', 'jaxlib', 'zarr', 'zmq', 'panel', 'holoviews',"
        " 'netCDF4', 'gfs_dynamical_core') if m in new]\n"
        "print('IMPORTED:' + ','.join(bad))\n"
    )
    result = subprocess.run(
        [sys.executable, "-c", code], capture_output=True, text=True, check=True)
    assert result.stdout.strip().splitlines()[-1] == "IMPORTED:"
```

`envs/climt-dev.in` and `envs/climt-dev.lock.txt` are always resolved relative to the repository that contains the script, never relative to `CLIMT_DIR` or the current directory.

Bootstrap behaviour, in order:
1. Parse flags. `--dry-run` prints each command it would run, prefixed `DRY-RUN: `, and runs none of them.
2. If the environment named `CLIMT_DEV_ENV_NAME` exists (`conda env list`) and `--recreate` was not passed: print `environment '<name>' already exists; pass --recreate to rebuild it` to stderr and exit 2. With `--recreate`: `conda env remove -n <name> -y` first.
3. `conda create -n <name> -y python=3.11 pip`.
4. Install requirements: with `--relock`, or when `envs/climt-dev.lock.txt` does not exist, `pip install -r envs/climt-dev.in`; otherwise `pip install -r envs/climt-dev.lock.txt`. All pip calls go through `conda run -n <name> python -m pip`.
5. Install climt: `pip install -e "$CLIMT_DIR"`. If that fails, print `compiled build failed; falling back to pure Python` and run `CLIMT_PURE_PYTHON=1 pip install -e "$CLIMT_DIR"`.
6. If `GFS_DYCORE_DIR` is set and is a directory: write `gfs_dynamical_core.pth`, containing that directory's absolute path, into the new environment's site-packages (no build, no dependency resolution); otherwise print `GFS_DYCORE_DIR not set or not a directory; skipping gfs_dynamical_core`. A failure here prints `gfs_dynamical_core link failed; continuing` and does not stop the script.
7. With `--relock`, or when the lock did not exist: write `pip freeze --exclude-editable` to `envs/climt-dev.lock.txt`.
8. Run `scripts/verify_dev_env.py` in the new environment and exit with its status.

Verification checks, in this order (`name` values verbatim):

| name | required | passes when |
|---|---|---|
| `climt import` | yes | `import climt` succeeds; detail is `climt.__version__` |
| `numba` | yes | an `@numba.njit` function summing `np.arange(10.0)` returns `45.0` |
| `jax cpu x64` | yes | after `jax.config.update("jax_enable_x64", True)`, `jax.devices()[0].platform == "cpu"` and `jnp.arange(3.0).sum()` is `3.0` with dtype `float64` |
| `no jax-metal` | yes | `importlib.metadata.version("jax-metal")` raises `PackageNotFoundError` |
| `climt component` | yes | `climt.GrayLongwaveRadiation()` called on `climt.get_default_state([component])` returns an `air_temperature` tendency with all values finite |
| `io stack` | yes | `zmq`, `zarr`, `panel`, `holoviews` all import; detail lists their versions |
| `fortran extensions` | no | `climt.has_fortran_extensions()` is `True` |
| `gfs_dynamical_core` | no | `import gfs_dynamical_core` and `import gfs_dynamical_core.jax.stepper` succeed |

Each check catches its own exception and records `repr(exc)` as `detail`; one failing check never stops the others. Default output is one line per check, `"{name:<22} {status}  {detail}"`, where status is `OK`, `FAIL`, or `MISSING (optional)`, followed by the `climt.show_versions()` lines. `--json` prints `json.dumps(run_checks())` and nothing else.

```python
import importlib.util
import json
import os
import subprocess
import sys
from pathlib import Path

REPO = Path(__file__).resolve().parent.parent
BOOTSTRAP = REPO / "scripts" / "bootstrap_dev_env.sh"
VERIFY = REPO / "scripts" / "verify_dev_env.py"


def _fake_conda(tmp_path, existing_envs=""):
    """A stand-in `conda` that lists `existing_envs` and logs every call."""
    log = tmp_path / "conda_calls.log"
    fake = tmp_path / "conda"
    fake.write_text(
        "#!/bin/bash\n"
        'echo "$@" >> "{log}"\n'
        'if [ "$1" = "env" ] && [ "$2" = "list" ]; then\n'
        '  printf "# conda environments:\\nbase  /x/base\\n{envs}"\n'
        "fi\n".format(log=log, envs=existing_envs))
    fake.chmod(0o755)
    return fake, log


def test_requirements_file_pins_the_jax_stack_and_omits_jax_metal():
    text = (REPO / "envs" / "climt-dev.in").read_text()
    for line in ("jax==0.10.1", "jaxlib==0.10.1", "s2fft==1.4.0",
                 "flax==0.12.7", "optax==0.2.8", "numba>=0.64", "numpy>=2.0",
                 "pyzmq", "zarr", "panel", "holoviews"):
        assert line in text.splitlines()
    assert "jax-metal" not in text


def test_bootstrap_refuses_to_touch_an_existing_environment(tmp_path):
    fake, log = _fake_conda(tmp_path, existing_envs="climt-dev  /x/envs/climt-dev\\n")
    env = dict(os.environ, CONDA_EXE=str(fake))
    result = subprocess.run(["bash", str(BOOTSTRAP)], env=env,
                            capture_output=True, text=True)
    assert result.returncode == 2
    assert "already exists; pass --recreate" in result.stderr
    calls = log.read_text()
    assert "remove" not in calls and "create" not in calls


def test_bootstrap_dry_run_runs_nothing_and_names_each_step(tmp_path):
    fake, log = _fake_conda(tmp_path)
    env = dict(os.environ, CONDA_EXE=str(fake), CLIMT_DIR=str(REPO))
    env.pop("GFS_DYCORE_DIR", None)
    result = subprocess.run(["bash", str(BOOTSTRAP), "--dry-run"], env=env,
                            capture_output=True, text=True)
    assert result.returncode == 0
    out = result.stdout
    assert "DRY-RUN: " in out
    assert "python=3.11" in out
    assert "pip install -e" in out
    assert "GFS_DYCORE_DIR not set or not a directory" in out
    calls = log.read_text()
    assert "create" not in calls and "run" not in calls


def test_bootstrap_dry_run_installs_dycore_without_deps(tmp_path):
    fake, _ = _fake_conda(tmp_path)
    dycore = tmp_path / "gfs"
    dycore.mkdir()
    env = dict(os.environ, CONDA_EXE=str(fake), CLIMT_DIR=str(REPO),
               GFS_DYCORE_DIR=str(dycore))
    result = subprocess.run(["bash", str(BOOTSTRAP), "--dry-run"], env=env,
                            capture_output=True, text=True)
    assert "--no-deps -e {}".format(dycore) in result.stdout


def _load_verify():
    spec = importlib.util.spec_from_file_location("verify_dev_env", VERIFY)
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def test_verify_reports_every_check_by_name_and_never_raises():
    checks = _load_verify().run_checks()
    assert [c["name"] for c in checks] == [
        "climt import", "numba", "jax cpu x64", "no jax-metal",
        "climt component", "io stack", "fortran extensions",
        "gfs_dynamical_core"]
    assert [c["required"] for c in checks] == [True] * 6 + [False] * 2
    for c in checks:
        assert isinstance(c["ok"], bool) and isinstance(c["detail"], str)


def test_verify_json_output_and_exit_status_follow_required_checks():
    result = subprocess.run([sys.executable, str(VERIFY), "--json"],
                            capture_output=True, text=True)
    checks = json.loads(result.stdout)
    required_ok = all(c["ok"] for c in checks if c["required"])
    assert result.returncode == (0 if required_ok else 1)


def test_verify_marks_a_failing_optional_check_as_missing_optional(monkeypatch, capsys):
    module = _load_verify()
    monkeypatch.setattr(module, "run_checks", lambda: [
        {"name": "climt import", "required": True, "ok": True, "detail": "x"},
        {"name": "fortran extensions", "required": False, "ok": False, "detail": "no"}])
    assert module.main([]) == 0
    assert "MISSING (optional)" in capsys.readouterr().out
    assert module.main(["--strict"]) == 1
```
