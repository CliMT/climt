## Task 9: HD 209458b T-p profile

### What's done
- `scripts/generate_hd209458b_reference.py` — computes the Parmentier & Guillot (2014) **analytic** T-p profile using climt's own `solar_composition.npz` + Freedman (2014) opacity coefficients. Uses the Guillot (2010) three-band formula. Run it with `conda run -n climt python scripts/generate_hd209458b_reference.py`.
- `docs/radiative_transfer/figures/hd209458b_reference.csv` — generated (300 rows, p: 1.2e-6 to 1.26 bar, T: 1275→1094→1648 K — has a thermal inversion).
- `tests/test_hd209458b_reproduction.py` — written but needs redesign (see below).

### The problem
The P&G analytic profile is **not a fixed point** of the numerical Parmentier solver:
- γ_v1 ≈ 6.3 (high visible opacity) causes 99.8% of the 250 kW/m² stellar flux to be absorbed in the upper atmosphere (p < 0.1 bar).
- LW only emits 113 kW/m² at the analytic profile — a 137 kW/m² imbalance.
- Upper atmosphere (levels 23–25, p ≈ 0.025–0.07 bar) has +30–65 K/hr SW heating with no LW balance.
- Root cause: P&G analytic assumes equal weights for 3 SW bands (w_j=1/3); numerical SW uses actual solar spectrum, concentrating flux in high-opacity band 1.

### Agreed test design (all 3 sub-checks in one test)
The user agreed to implement all three checks:

**A. OLR energy-balance check** — after equilibrating, assert:
```
LW OLR ≈ σ*(T_int⁴ + T_irr⁴) = 254,203 W/m²  within 10%
```
Parameters: T_irr=1450 K, T_int=500 K, μ_star=1 (zenith=0), A_B=0.

**B. T-profile regression (deep atmosphere only)** — run model to numerical convergence, save converged T-p as a **second** CSV (`hd209458b_model_equilibrium.csv`), assert future runs match it within 2%.

**C. Narrow P&G analytic comparison** — compare only at p > 0.3 bar (levels 0–15 in the 28-level hot_jupiter default state), where initial tendencies are ≤ 2 K/hr and P&G analytic is reliable. Tolerance 15%.

### Numerical stability notes
- **Surface temperature bug**: must set `state['surface_temperature'].values[:] = T_init[0]` (bottom level, p≈1 bar), NOT `T_init[-1]` (TOA).
- TOA level (level 27, p=0.0026 bar) has -418 K/hr tendency; use dt=300–600 s or clip T to avoid overflow.
- Deep levels (0–7, p>0.7 bar) have ±0–23 K/hr → converge cleanly.
- Level 26 (p=0.011 bar) is nearly at analytic equilibrium (-0.47 K/hr) — good anchor.

### Reference values
```
HD 209458b (Torres et al. 2008):  g = 9.42 m/s², R = 3614 J/kg/K, cp = 13000 J/kg/K
T_irr = 1450 K, T_int = 500 K, zenith_angle = 0°
T_eff = (T_int⁴ + T_irr⁴)^0.25 = 1455 K
σ*T_eff⁴ = 254,203 W/m²   ← target OLR at equilibrium
```
